# Visible Armor Slots
![Armor and off hand slots next to a container](docs/images/placeholder-minecraft-26.3.webp)

Visible Armor Slots is a small client-side utility mod that pins your armor slots (and, optionally, your off hand slot) next to container screens, so you can equip, swap, or drop gear without opening your inventory.

It also supports some more advanced features, such as a dark mode, quick actions for equipping, swapping, and dropping items, automatic mirroring to the other side while the recipe book is open, and deep configuration, from the slots' position to which containers they appear in.

![Dark Mode](docs/images/placeholder-minecraft-26.3.webp)

# 📦 Supported Containers
Visible Armor Slots works out of the box with all vanilla and most modded containers.

# 📥 Installation
Make sure you have [Fabric Loader](https://fabricmc.net/use) and [Fabric API](https://modrinth.com/mod/fabric-api) installed, then simply drop the mod into your _mods_ folder.

The mod is **client-side only**, so there's no need to install it on a server. It works on any server, even if the server doesn't have the mod.

# ⚙️ Configuration
![Mod Menu settings](docs/images/placeholder-minecraft-26.3.webp)

All settings can be changed in-game through [Mod Menu](https://modrinth.com/mod/modmenu).

**Not sure how to configure the mod?** Don't worry, you probably don't need to. The default settings work well for most players, so you can just install the mod and start playing.

# ❓ FAQ
**Is there a version for mod loader X?**

No, Visible Armor Slots is only available for Fabric, and that's unlikely to change. However, it should also work on Quilt, which can run most Fabric mods.

**Will the mod be backported to older Minecraft versions?**

No. Currently, the mod only supports the latest Minecraft release, and builds for earlier updates aren't planned.

**Is it safe to use on servers with anti-cheat?**

Yes. The mod only sends the same inventory clicks as vanilla, exactly as if you had opened your inventory yourself, so there's nothing for anti-cheat to flag.

**Can I include the mod in my modpack?**

Yes, as long as your modpack downloads the mod from Modrinth rather than including the file directly.
